《智惠本草》小程序需求文档（PRD）
一、 产品概述（这是干什么的？）
“智惠本草”是一款将公共空间应急用纸刚需与中医药文化科普深度融合的数智化便民服务与治理小程序 。
它主要依托线下智能出纸设备，打破传统公共设施功能单一的痛点 。对于普通用户（C端），它是一个提供便捷取纸、趣味答题赚取免费纸巾、学习中医药知识的沉浸式平台 ；对于管理方（B端），它是一个能实现精准控纸、节约资源、实时监控设备状态的精细化治理工具 。

二、 主要功能模块（有哪些主要功能？）
1. 核心业务模块（C端用户端）

开屏与广告加载：小程序启动时展示开屏页，可用于提供场景化广告服务（如中药厂、连锁药店等品牌联名推广） 。


扫码出纸与支付：用户通过扫码进入专属小程序，完成支付操作后，驱动线下设备吐出环保竹纤维纸巾 。


趣味答题与奖励机制：用户每次取纸后，系统触发中医药知识答题模块 。用户若答对题目，即可获得下一次免费兑换纸张的资格凭证（兑换码或积分） 。


个性化科普推送：系统引入AI算法，定期为用户精准推送中医药文化科普知识、二十四节气养生AI建议等个性化内容 。


AR识药互动体验：调用手机摄像头，用户扫描印有中草药图案的纸巾，即可在小程序内交互查看3D药材模型与养生功效动画 。

2. 治理与运维模块（B端管理端/后台）

设备状态实时监控：提供地图模式或列表模式，实时展示各点位设备的在线状态、耗材剩余量与故障自动报修提醒 。


数据分析与热力图：动态生成各公共场所（学校、医院、地铁站等）的“用纸热力图”，帮助管理方掌握消耗规律，实现智慧补给 。


用户与题库管理：支持运营人员在后台更新科普文章、原创本草主题题库以及设备屏幕的投放内容 。

三、 界面布局建议（界面是怎样的？）
首页（扫码与取纸）：

顶部：用户地理位置及附近可用设备提示。

核心区：巨大的“扫码取纸”按钮或扫描框。

底部弹窗/浮层：取纸成功后的“答题赢免单”强引导入口。

科普与互动页（发现/社区）：

顶部Tab：分为“AR识图”、“AI养生建议”、“科普文章”。

信息流：以卡片形式展示中医药知识，结合图文与短视频。

个人中心（我的）：

展示用户的“免费领纸券”余额、累计节约纸张数（强调低碳环保成就） 。

展示用户的“中医药知识段位”或答题成就勋章。

B端管理看板（针对管理员账号展示）：

数据大屏风格，展示用纸量曲线、设备异常告警列表及网格化运维地图 。

四、 使用感觉与交互体验（用户体验是怎样的？）

视觉风格（国潮与科技的碰撞）：整体UI设计应采用“现代新国风”或“医工交叉”的科技感色调。可以将传统的草本绿、水墨元素与现代极简的卡片式设计结合，体现“有文化温度的现代公共服务”理念 。


操作流畅性（即扫即取）：核心的取纸流程必须极简，从扫码到出纸的响应时间应控制在毫秒级，满足高流转空间（如校园、地铁站）的应急痛点 。


情感化交互（从被动到主动）：答题环节引入游戏化机制（如音效、动画），让用户从传统的“被动接收”转化为“主动参与”的跃迁，实现“润物无声”的教育效果 。


适老化与无障碍（后期拓展）：针对社区卫生中心等场景，界面需支持一键切换“适老化大字版”，突出语音交互和慢病调理库的便捷访问 。
