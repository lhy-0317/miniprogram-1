《智惠本草》小程序前端需求文档（仅前端/预留接口版）
一、 总体设计风格视觉定位：现代医工交叉风（“草本绿”搭配“数智蓝”）。 设计原则：极简触发（应急场景下取纸速度第一）、沉浸交互（答题与AR环节的高互动性）。 
二、 核心页面结构与交互需求
1. 首页：扫码取纸入口 (Landing Page)功能描述：用户进入小程序的首屏，承载最高频的“应急”需求。 前端交互细节：扫码组件：调用微信原生扫码接口，识别设备二维码。 状态检查（预留接口）：扫码后调用 GET /api/device/status。若设备缺纸或故障，前端展示“维护中”置灰状态。 支付触发：点击“领纸”唤起微信支付 SDK。 动效预留：支付成功后，展示一个“指令已发送”的 Loading 动画，等待后端通过 WebSocket 或轮询返回“出纸成功”信号。 
2. 趣味答题页 (Quiz Module)功能描述：出纸后自动弹出，通过游戏化机制实现文化传播。 前端需求：题目渲染：从预留接口 GET /api/quiz/random 获取题干、选项及背景图。 交互逻辑：选中选项后即刻反馈对错（变绿/变红），答对时触发“烟花”动效，并弹出“获得免费券”的 Modal 弹窗。 数据提交：答题结束调用 POST /api/quiz/submit，将用户答题时长与结果埋点上传。 
3. AR本草识图页 (AR Experience)功能描述：扫描纸巾上的药材图案，展示 3D 模型或动画。 前端需求：相机权限：申请摄像头权限。 识别追踪：利用小程序 vision kit 或第三方 AR 插件识别纸巾特定图案（特征点追踪）。 模型渲染：识别成功后，叠加 WebGL 渲染的 3D 药材模型，支持手势旋转、缩放。 
4. 个人中心与健康看板 (User Profile)前端需求：数据展示：调用 GET /api/user/stats 展示“已节约纸张数”、“累计答题数”。 券包列表：展示答题获得的“免单券”，需具备“有效期”过滤功能。
5. 开屏页功能描述：扫码后自动弹出，持续5s，右上角可点击关闭，提供场景化广告服务(为以后预留，目前可以用中医药相关图片)，可点击跳转广告链接。
三、 前端组件化建议（预留后端对接）组件名称核心逻辑预留后端关联字段建议DeviceStatus监听后端推送，实时切换设备可用性。device_id, is_online, stock_levelQuizCard动态渲染题库，支持图文、视频多模态。question_type, options_array, correct_idPaperCoupon优惠券核销组件，生成唯一核销码。coupon_token, expiry_dateBannerAds开屏与底部广告位，支持按场景 ID 加载。ad_image_url, target_link
四、 使用感觉描述快：用户在急需用纸时，扫码到支付响应必须在 2秒内 完成，前端需做好资源预加载。 雅：在科普页滑动时，文字排版参考《本草纲目》古籍风格，但配图使用高清 3D 建模，体现“数智化”质感。 爽：答题环节不应有挫败感，题目设计应简单有趣，答对后的反馈（振动+视觉）要强，鼓励用户二次参与。
